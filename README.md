# OpenCut Pessoal

Este é o repositório principal do OpenCut Pessoal. O endereço `https://pampfelp.github.io/` abre o editor em `/opencut/`. O código-fonte está em `source/` e os arquivos publicados do editor estão em `opencut/`. A apresentação aprovada está em `/sobre.html`; a política de privacidade e os termos estão em `/privacidade.html` e `/termos.html`.

O editor roda no navegador. Projetos e mídias ficam primeiro no armazenamento local de cada aparelho; a sincronização opcional usa a conta Google Drive autorizada pelo usuário. O repositório contém somente os arquivos do aplicativo, nunca os projetos pessoais ou vídeos.

O OpenCut Pessoal é uma adaptação do OpenCut Classic. A licença MIT acompanha a publicação em `LICENSE`.

Para desenvolver, use `source/`. As instruções de build e os limites da sincronização com o Google Drive estão em `source/README-PESSOAL.md`. O GitHub Pages publica a branch `main` a partir da raiz deste repositório.
